# Project Templates — General Guide

These are **starter templates**. Each one has **no solution/business logic implemented** —
only folder structure, base config files, and empty functions for you to fill in.

Pick a template below, download or clone it, and follow the setup steps.

## Setup Steps (same for every template)

1. **Download or clone** the template you want to work on.
   ```bash
   git clone <repo-or-zip-link>
   ```
2. **Enter the project folder.**
   ```bash
   cd <project-folder-name>
   ```
3. **Install dependencies** — this is the only setup command needed.
   ```bash
   npm install
   ```
4. Check the `.env` file and fill in your own values (DB connection, secrets, port, etc).
5. Run the project:
   ```bash
   npm run dev
   ```
6. Open the project's own `.md` file (e.g. `freelance.md`, `gym.md`, `housing.md`, `medical.md`) inside its folder — that file explains the structure and lists what needs to be built.
